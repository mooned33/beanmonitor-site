# BeanMonitor SEO V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn BeanMonitor's existing daily market data into a small, high-quality set of indexable static pages with current homepage data, consistent canonicals, useful internal linking, and no thin programmatic pages.

**Architecture:** `beanmonitor` remains the private collector and publishes a richer `public-market.json`. `beanmonitor-site` consumes that snapshot at build time and renders all SEO pages as static HTML. No CMS, runtime backend, or new framework is introduced.

**Tech Stack:** Node.js 22, ES modules, GitHub Actions, static HTML/CSS/JS, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-09-11-seo-v2-design.md`

## Global Constraints

- Do not modify either repository's `main` branch during implementation.
- Canonical host is exactly `https://www.beanmonitor.coffee`.
- Generated SEO pages are English only in this phase.
- Do not create per-lot, per-day, per-news or per-GPS-point pages.
- A country-season COE page is generated only when at least 5 auction result lots exist.
- When seasonal normal rainfall is below 5 mm, weather copy must show both the ratio and the absolute observed/normal values.
- Existing Buttondown, Stripe, email delivery and subscription logic remain unchanged.
- Existing top-level `public-market.json` fields stay backward-compatible.

- [ ] **Step 3: Add auction statistics helpers**

Implement deterministic helpers:

```js
function validBidLots(lots) {
  return (lots || []).filter((l) => Number.isFinite(l.bidPerLb) && l.bidPerLb > 0);
}

function median(values) {
  const xs = [...values].filter(Number.isFinite).sort((a, b) => a - b);
  if (!xs.length) return null;
  const m = Math.floor(xs.length / 2);
  return xs.length % 2 ? xs[m] : (xs[m - 1] + xs[m]) / 2;
}

function auctionStats(lots) {
  const xs = validBidLots(lots);
  if (!xs.length) return null;
  const weighted = xs.filter((l) => Number.isFinite(l.weightLb) && l.weightLb > 0);
  const weightedAvg = weighted.length
    ? weighted.reduce((s, l) => s + l.bidPerLb * l.weightLb, 0) / weighted.reduce((s, l) => s + l.weightLb, 0)
    : xs.reduce((s, l) => s + l.bidPerLb, 0) / xs.length;
  const scores = xs.map((l) => l.score).filter(Number.isFinite);
  const top = [...xs].sort((a, b) => b.bidPerLb - a.bidPerLb)[0];
  return {
    lots: xs.length,
    weightedAvg,
    medianBid: median(xs.map((l) => l.bidPerLb)),
    topBid: top.bidPerLb,
    topFarm: top.farm || "Unknown farm",
    avgScore: scores.length ? scores.reduce((s, v) => s + v, 0) / scores.length : null,
  };
}
```

- [ ] **Step 4: Add a top-buyers helper**

Implement:

```js
function topBuyers(lots, limit = 5) {
  const counts = new Map();
  for (const lot of lots || []) {
    const buyer = String(lot.buyer || "").trim();
    if (!buyer) continue;
    counts.set(buyer, (counts.get(buyer) || 0) + 1);
  }
  return [...counts.entries()]
    .sort((a, b) => b[1] - a[1] || a[0].localeCompare(b[0]))
    .slice(0, limit);
}
```

function weatherContext(r) {

  if (lowBase) {
    return `${num(r.pctOfNormal, 0)}% of seasonal normal, based on ${num(r.rain7d)} mm observed versus a very low ${num(r.normal7d)} mm seasonal normal. The ratio is visually large because the seasonal baseline is small.`;
